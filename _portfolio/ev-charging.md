## Overview

Implementation of the ISO 15118 Vehicle-to-Grid communication protocol on an STM32H7 microcontroller, enabling smart charging and bidirectional energy transfer.

## Tech Stack
- **MCU:** STM32H7
- **Protocol:** ISO 15118, PLC (HomePlug GreenPHY)
- **Language:** C
- **Tools:** STM32CubeIDE, GDB, Wireshark

## Key Challenges
- Real-time protocol handling on bare metal
- TLS handshake implementation on constrained hardware
- Power line communication signal integrity

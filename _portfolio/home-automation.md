## Overview

Custom-built environmental sensors using ESP32, communicating over MQTT with a Home Assistant instance for whole-home monitoring.

## Tech Stack
- **MCU:** ESP32
- **Protocol:** MQTT, Wi-Fi
- **Integration:** Home Assistant, ESPHome
- **Language:** C++

## Features
- Temperature, humidity, and air quality monitoring
- Low-power design with battery operation
- OTA firmware updates
- Custom PCB design

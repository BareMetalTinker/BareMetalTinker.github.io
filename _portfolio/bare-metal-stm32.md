## Overview

A series of bare metal firmware projects on STM32F4, written entirely at the register level without relying on HAL libraries or an RTOS.

## Tech Stack
- **MCU:** STM32F4
- **Language:** C
- **Tools:** ARM GCC, OpenOCD, GDB, Make

## Topics Covered
- GPIO, UART, SPI, I2C drivers from scratch
- Timer configuration and PWM generation
- DMA transfers
- Interrupt handling and NVIC configuration
- Custom linker scripts and startup code
